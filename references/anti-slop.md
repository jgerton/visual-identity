# Anti-Slop Validation

Run all checks on every output before presenting to the user. If output fails any check, revise before delivering. Show the user which check failed and the before/after revision.

---

## 1. Swap Test (Neumeier)

**Question:** Could you swap in a competitor's name and this statement would still work?

**How to apply:** Take every positioning statement, onlyness statement, tagline, value proposition, or brand description. Replace the brand name with a competitor's name. If it reads just as well, the output is generic and must be revised.

**Fail:** "Oferecemos soluções inovadoras que ajudam organizações a crescer."
**Pass:** "A única rede colaborativa da Amazônia que conecta dados territoriais de 772 municípios com pesquisadores locais em cinco dimensões integradas."

---

## 2. Hand Test (Neumeier)

**Question:** Cover the brand name. Can you tell whose piece this is?

**How to apply:** Take any copy, description, or analysis. Hide the brand identity. If a stranger couldn't identify the brand from the remaining content, the output lacks distinctiveness.

**Fail:** A description that could belong to any sustainability network.
**Pass:** Content with specific references to the brand's unique structure, territory, audience, or methodology that only this brand would have.

---

## 3. Specificity Test

**Question:** Does the output contain banned generics?

**PT-BR banned words/phrases:**
- "inovador" / "inovação" (sem especificar o quê)
- "de ponta"
- "de classe mundial"
- "revolucionário"
- "sinergias"
- "alavancar"
- "empoderar"
- "soluções" (sem especificar quais)
- "apaixonado por"
- "holístico"
- "transformar" (sem especificar de-quê para-quê)
- "excelência"
- "vanguarda"
- "diferenciado" (sem dizer como)
- "comprometido com" (sem especificidades)
- "sustentável" (quando usado como adjetivo genérico, não quando descreve práticas concretas)

**EN banned words/phrases:**
- "innovative" / "innovation"
- "cutting-edge"
- "best-in-class"
- "world-class"
- "next-generation"
- "revolutionary"
- "game-changing"
- "seamless"
- "holistic"
- "synergy"
- "leverage" (as marketing verb)
- "empower"
- "transform" (without specifying from-what to-what)
- "solutions" (without specifying the solution)
- "passionate about"

**How to apply:** Scan all output. Each banned instance must be replaced with a specific, concrete claim. "Rede inovadora" becomes "rede que integra dados de 772 municípios com pesquisadores em cinco dimensões operacionais."

---

## 4. Differentiation Test (Dunford)

**Question:** Is the claimed value tied to specific, unique attributes?

**How to apply:** For every value claim, trace it back to a specific capability or attribute that the brand uniquely has. If the value claim floats without an anchor, it fails.

**Fail:** "Conectamos pessoas para o desenvolvimento sustentável." (How? Everyone claims this.)
**Pass:** "A base de dados territorial cobre 772 municípios da Amazônia Legal, permitindo análises espaciais que nenhuma outra rede regional oferece." (Tied to a specific, verifiable asset.)

---

## 5. Voice Contrast Test

**Question:** Are there explicit "is NOT" statements?

**How to apply:** Brand personality output must include what the brand is NOT, not just what it is. Voice without contrast is voice without edges. Every personality definition should include at least 3 "NOT" statements.

**Fail:** "A marca é séria e acessível."
**Pass:** "Rigorosa mas NÃO fria. Amazônica mas NÃO cartão-postal. Institucional mas NÃO burocrática. Soa como um pesquisador experiente explicando seu trabalho a um colega de outra área, NÃO como um relatório governamental."

---

## 6. Business-Type Test

**Question:** Would this output work equally well for a completely different type of organization?

**How to apply:** If you could transplant the output to a different business type and industry without changing anything, it's too generic. Output must reflect the specific business context, audience, and competitive landscape.

**Fail:** A positioning statement that works for any NGO or network.
**Pass:** A positioning statement that only works for a collaborative research network operating across the Legal Amazon with integrated science, technology, innovation, communication, and data dimensions.

---

## 7. SMP Quality Criterion

**Applies to:** Skill 3 (visual-direction) SMP generation. Referenced here for completeness.

**Question:** Does the SMP contain at least one element that would not exist without the diagnosis?

**How to apply:** If a designer could have written this SMP from just the client brief (without running the diagnosis), it's too generic. The SMP must incorporate real competitive intelligence: a positioning insight, a market gap, an unoccupied territory, a specific differentiator surfaced by research.

**Fail:** "Conhecimento e conexão para a Amazônia." (Could be written without any research.)
**Pass:** An SMP that references the specific gap identified in the chromatic territory, the competitive white space, or a differentiator only visible through the diagnosis process.
